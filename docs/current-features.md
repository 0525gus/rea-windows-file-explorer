# 추가 기능 구현 (2026-10-22)

이 문서는 기존 동결 평가 이후의 구현을 설명한다. 이번 변경에서는 테스트와 앱 실행 검증을 하지 않았으며, 컴파일만 확인한다. 기존 검증 결과를 이번 코드의 통과 결과로 사용하지 않는다.

- **즐겨찾기:** 현재 폴더에서 Ctrl+D로 추가/제거. 왼쪽 Favorites에서 이동하고 항목 우클릭으로 제거한다.
- **설정·탭 복원:** 정상 종료 시 창 크기·위치, 분할창, 열 너비, 보기 모드, 미리보기 표시, 열린 탭 경로(최대 20개), 활성 탭을 저장한다. 복원할 폴더가 없으면 해당 탭은 This PC로 열린다. 탐색 기록·검색어는 복원하지 않는다.
- **자동 새로고침:** 열린 탭의 폴더 변경을 감시하고 350ms 단위로 합쳐 새로고침한다. 현재 탭 파일의 내용 변경도 감시한다(감시 경로 512개 한도). 파일 작업 중에는 반영을 미룬다. OS 감시 한도·네트워크 드라이브 등에서 알림이 없으면 F5를 사용한다.
- **미리보기:** 단일 일반 파일 선택 시 세부 정보 패널에서 이미지 또는 텍스트를 비동기로 읽는다. 심볼릭 링크 제외, 파일 크기 32MiB 이하, 이미지 3,200만 화소 이하, 텍스트 앞 32KiB. 이미지 형식은 설치된 Qt 플러그인이 지원하는 범위이다. View 메뉴에서 패널을 숨기거나 표시한다. 목록 썸네일은 아래 추가 구현을 참고한다.
- **우클릭 메뉴:** 열기, 폴더를 새 탭에서 열기, 잘라내기/복사/이름 변경/휴지통, 경로 복사, 기본 속성, 빈 영역의 붙여넣기/새 폴더/새로고침을 제공한다. 앱 메뉴에 Windows 네이티브 메뉴 진입점도 제공한다(아래 참고).
- **인라인 이름 변경:** F2 또는 Rename으로 파일 목록 안에서 이름을 편집하고 Enter로 적용, Escape로 취소한다. 실제 변경은 기존 파일 작업 계층에서 수행한다.
- **상세 검색:** `?`로 시작하면 아래 필터를 AND로 적용한다. 일반 입력은 기존처럼 전체 문자열 이름 검색이다. 기본은 현재 폴더이며 Search subfolders를 켜면 하위 폴더까지 검색한다.

```text
? ext:png,jpg
? type:file size:>1mb
? after:2026-01-01 before:2026-10-22
? ext:txt name:"meeting notes"
```

`type:file|folder`, `ext:확장자[,확장자]`, `size:비교값`, `after:YYYY-MM-DD`, `before:YYYY-MM-DD`, `name:문자열` 및 일반 이름 단어를 지원한다. 날짜는 수정일 기준, 양끝 포함이다. 크기는 B/KB/MB/GB 또는 KiB/MiB/GiB이며 모두 1024 기준이다. 비교는 `>`, `>=`, `<`, `<=`, `=`(생략 가능)이다. 잘못된 크기/날짜 필터는 일치 결과가 없다.

## 남은 다섯 기능 추가 구현

### Undo / Redo

파일 목록에 포커스가 있을 때 Ctrl+Z로 실행 취소, Ctrl+Y 또는 Ctrl+Shift+Z로 다시 실행한다. 우클릭 메뉴에도 최근 작업 이름과 함께 표시한다.

복사, 이동, 이름 변경, 새 폴더, 휴지통 이동을 지원한다. 여러 항목의 성공한 작업을 묶어서 기록하며 실패/취소된 항목은 기록하지 않는다. 복사·새 폴더를 되돌릴 때는 생성물을 OS 휴지통으로 보내고 다시 실행 시 해당 항목을 복원한다. 휴지통 이동도 OS가 반환한 실제 휴지통 항목을 기록하여 복원한다. 이동/이름 변경은 원래 경로로 되돌리며, 다른 볼륨으로 이동한 항목의 후속 기록도 새 파일 식별자에 맞춰 연결한다.

파일 식별자·크기·수정 시각·폴더 자식 목록을 확인하므로 외부에서 바뀐 항목은 덮어쓰거나 삭제하지 않고 오류로 알린다. 대상 이름 충돌은 실패하며, Windows 복원 중 외부에서 충돌이 생기면 Shell이 충돌 없는 이름을 선택할 수 있다. 정상 실패 항목은 재시도할 수 있고 부분 변경 항목은 자동 재시도 기록에서 제외한다. 최근 50개 작업, 추정 64MiB 이내 기록을 유지하며 한도를 넘어서 기록할 수 없는 항목은 작업 상태 영역에 알린다. 기록은 현재 앱 실행 동안 유지한다. OS 휴지통이 없는 볼륨, 비워진 휴지통, 외부에서 수행한 네이티브 메뉴 작업은 앱 Undo 대상으로 보장하지 않는다. Windows 네이티브 메뉴 자체의 OS Undo는 별도이다.

### Windows 네이티브 메뉴

우클릭 → Windows context menu, 또는 Shift+우클릭으로 실제 IContextMenu를 연다. 빈 영역에는 해당 Shell 폴더의 배경 메뉴를 연다. IContextMenu2/3 메시지와 동적 하위 메뉴를 전달하므로 설치된 Shell 확장도 사용할 수 있다. 여러 항목은 같은 Shell 부모 폴더에 있는 선택을 지원한다. 재귀 검색에서 서로 다른 폴더의 항목을 섞어 선택했다면 앱 작업 메뉴를 사용하거나 같은 폴더끼리 선택한다.

### Windows Shell 특수 위치

왼쪽 Windows Shell 그룹에서 Desktop namespace, Recycle Bin, Network, Libraries, Control Panel, Applications를 연다. 주소창의 `shell:RecycleBinFolder`, `shell:Libraries`, `shell:AppsFolder` 같은 Shell 이름과 `::{GUID}`도 받을 수 있다. 가상 폴더를 열거하고 하위 위치 이동·상위 이동·탭 기록·파일/앱 열기를 제공한다. ZIP 및 라이브러리처럼 물리 파일이면서 Shell 폴더로 노출되는 항목도 Shell 항목으로 유지한다. 특수 위치의 생성/삭제/복원 등 OS 동작은 네이티브 메뉴에서 수행한다. Shell 특수 위치를 즐겨찾기와 탭 복원에도 저장할 수 있다. 시스템 제공 namespace/확장의 설치·접근 권한에 따라 항목과 지원 동작은 달라진다.

### 목록 썸네일

자세히/목록/아이콘 보기에서 화면에 요청된 항목을 백그라운드로 읽고 갱신한다. Qt 이미지 썸네일을 먼저 시도하고 Windows에서는 IShellItemImageFactory를 통해 등록된 이미지·문서·영상 썸네일 공급자와 시스템 아이콘을 사용한다. 이미지/공급자가 없으면 파일/폴더 아이콘을 유지한다. 캐시는 약 16MiB, 디코딩은 2개 worker/8개 대기 요청으로 제한한다. View → File thumbnails에서 켜고 끄며 설정을 저장한다. 배포물에 JPEG/GIF/ICO Qt 플러그인도 포함한다.

### 재귀 검색

검색창 왼쪽 폴더 버튼 → Search subfolders를 켠다. 일반 이름 검색과 기존 `?` 상세 필터 모두 하위 폴더에 적용된다. 입력을 250ms 단위로 합치고 백그라운드에서 탐색한다. 검색창에서 Escape 또는 메뉴의 Cancel search로 취소한다. 결과 우클릭 → Open containing folder in new tab으로 원래 위치를 연다. 재귀 검색 결과의 Rename은 결과 항목의 실제 부모 폴더에서 수행한다.

접근 불가 하위 폴더는 건너뛰고 상단에 알린다. 링크/reparse point는 재귀 진입하지 않는다. 최대 100000개 결과/64MiB, 100000개 폴더 및 16MiB 대기 경로 한도가 있으며 잘린 결과는 배너로 알린다. 최대 384개 검색 폴더의 변경 감시를 등록하되 전체 감시 경로 512개 제한과 OS 한도를 따른다. Search subfolders와 탭별 보기 모드도 정상 종료 시 저장한다. 가상 Shell 위치에는 파일시스템 재귀 검색 대신 해당 위치의 탐색/네이티브 메뉴를 사용한다.

## 구현과 검증 범위

위 다섯 항목은 소스와 UI 연결까지 구현했다. 테스트·앱 실행 검증은 사용자 요청으로 수행하지 않는다. Windows x64/MinGW-w64/Qt 6.11.1 및 Linux x86_64/Qt 6.4.2에서 앱 target만 컴파일하여 기록한다. 기존 평가/테스트 통과 기록을 새 기능의 실행 검증 결과로 사용하지 않는다. 기존 취소 기능과 다크 테마는 유지한다.
